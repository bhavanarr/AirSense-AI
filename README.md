# Air-Sense AI

A machine learning-based air quality monitoring and forecasting system for multiple Indian cities.

## Objectives
- Predict PM2.5 air pollution levels.
- Compare machine learning and deep learning models.
- Detect unusual air-quality patterns.
- Evaluate forecast reliability under missing monitoring data.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- XGBoost
- PyTorch
- Streamlit
- Plotly

## Project Structure
- `notebooks/` – Model development notebooks
- `src/` – Python source code
- `data/` – Dataset storage
- `models/` – Trained models
- `results/` – Evaluation results
